## 2026-05-22 - Conditional ARIA Descriptions for Dynamic Forms
**Learning:** When adding form validation accessibility to custom React forms (like `UnifiedContactForm.jsx`), `aria-describedby` must be conditional (e.g., `aria-describedby={errors[field.name] ? \`error-${field.name}\` : undefined}`) rather than always pointing to an ID. If it always points to an ID but the element with that ID is conditionally unmounted (like a framer-motion `motion.span` when there is no error), screen readers may get confused by the missing reference. Additionally, `aria-invalid` must be explicitly toggled to true/false based on the error state.
**Action:** Always make `aria-describedby` conditional in React forms when the corresponding error element is not persistently in the DOM, and ensure `aria-invalid` strictly matches the validation state.
